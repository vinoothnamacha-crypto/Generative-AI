# AuraGen - UI Self-Healing & Telemetry Pipeline

An autonomous real-time system that captures user cognitive friction (e.g., rage clicks) via WebSockets and dynamically morphs the frontend UI into a simplified, accessible layout.

## 🚀 Features
- **Real-Time Telemetry:** Live WebSocket communication on port 8080.
- **Rage Click Engine:** Detects high user friction automatically.
- **AST Code Validation:** Ensures dynamic UI payloads pass security checks.
- **Self-Healing UI:** Morphs component views on screen live without page reloads.
