# Generative-AI
**TITLE:AuraGen: Self-Healing Generative UI via Cognitive Load**
AuraGen is an AI-powered web application that dynamically adapts its user interface based on the user's cognitive load and interaction patterns. Instead of relying on static interfaces or external chatbots, the system detects user frustration through mouse movements, hesitation, and click behavior. When high cognitive friction is identified, an AI-powered code generation pipeline creates a simplified React component and seamlessly updates the interface in real time without requiring a page refresh.This project combines modern frontend technologies with Generative AI to deliver an intelligent, adaptive, and user-friendly experience.
**Key Features**
Real-time cognitive load detection using user interaction data.
AI-generated React UI components using LangChain and LLMs.
Secure code validation with Babel AST.
Dynamic UI rendering using Next.js and React.
Real-time communication with WebSockets.
Smooth UI transitions and adaptive user experience.
